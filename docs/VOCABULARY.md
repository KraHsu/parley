# 词句收藏与复习

词句本、编辑、检索、备份和普通复习均可离线使用。只有点击解释、翻译或表达练习才请求所选的助手模型。

## 从对话保存材料

1. 在工作台的消息正文，或终端语法窗口自动同步的消息中，选中一个词、短语或句子。
2. 点击“收藏选中词句”。也可用 Tab 聚焦每条消息的“收藏整句”，或在词句页“添加词句”。
3. 检查语言、类型与原句，填写释义、个人注释和逗号分隔的标签，点击“保存词句”。可以先留空释义。

终端模式读取最近 6 个 turn。可切换最近消息，收藏自己的表达或 GPT 的回复；从 GUI 中同步的正文选择即可，无需复制。官方终端本身仍使用 Codex 原有选区和快捷键。选区固定期间正文不随轮询替换，点击“结束选择”显示最新内容。截取的来源会标注为片段。

原句作为独立快照保留：删除 Parley 聊天或无法读取原 Codex 会话，不会删除收藏材料。再次收藏同一处来源会提示已有记录；可以查看原收藏、补充另一次遇到的原句，或明确保存为另一种意思。补充原句保留已有释义；新填的释义、注释和标签仍保存在未完成草稿中。

有本地会话关联的原句提供“查看原消息”：先保存当前对话草稿，再打开原会话并定位消息。原消息已删除时保留词卡快照；导入材料或外部终端来源不提供本地跳转。独立语法窗口中，主对话来源以原对话阅读页打开，助手来源回到答疑页。

API 和 Claude Code GUI 回复下方显示服务返回的 token 计数，重启后仍可查看。缺失值不记作零，也不推算总量或费用；没有可识别计数时显示“服务未提供用量”。Codex 的官方额度信息仍在连接设置中。

## 使用语言助手的答案

在收藏表单点击“请助手解释”，表单收起后可在助手回复中选段，点击“用作释义”或“添加到注释”。内容先填入草稿，检查后再保存。

答疑会绑定发送时的草稿版本。回答期间如果切换或修改了词句，需核对后明确“确认改用于当前草稿”，才允许采用这份答案。不会在收到回复时自动改写词句。普通辅导回复也可以通过选段用于当前草稿。

模型未连接、无额度或请求失败时，仍可手动填写并保存本地材料。模型由设置中的可用列表选择，不要求账号提供特定型号。

## 查找、编辑与删除

- 在词句页搜索原文、释义或注释，按语言、类型、是否有释义、标签或复习状态筛选；每页最多 50 条。
- 查询采用 NFC 规范化，区分大小写和重音；不会按拼写自动合并不同意思。
- 编辑必须点击“保存词句”才更新正式词条。收起或关闭窗口会保存未提交草稿，在词句页“未完成草稿”继续编辑；草稿不计入收藏数。
- 遇到编辑冲突时保留草稿，可查看数据库最新版本、比较后明确保存。
- 删除先进入回收站，可立即恢复或稍后勾选“回收站”找回；彻底删除需再次确认，会移除这个词条的来源、卡片和评分历史。
- 独立语法窗口顶部有“答疑 / 词句 / 复习”入口，切换不会清空辅导草稿。

语言设置和词条均接受 BCP 47 语言代码，例如 `pt-BR`、`zh-Hant`、`ar`，不限于预设语言。词条可另填语言名称。修改全局语言不改变已有词条。

输入上限按 Unicode 标量值计算：词句 2,000、释义 8,000、注释 16,000、单条原句 16,000。超限时缩小选区或精简输入；不会静默截掉填写内容。每条词句最多 20 个标签，每个标签最多 50 个字符。

## 离线复习

在有释义的词条详情中，为需要的方向点击“加入复习”：

- 看到目标词句，回忆含义。
- 看到释义，回忆目标表达。

两个方向独立排程。打开复习页，默认每次最多 20 张、其中新卡最多 5 张，可调整；先复习已到期卡，再补充新卡。看提示、主动回忆、点击“显示答案”，最后自评：

| 自评 | 下次复习                                  |
| ---- | ----------------------------------------- |
| 忘记 | 10 分钟后，从初始阶段重新开始             |
| 吃力 | 1 天后，保留阶段                          |
| 记住 | 依次为 1、3、7、14、30 天，之后保持 30 天 |

这里一天按 24 小时计算，到期时间以本地时区显示。这是固定规则，不根据收藏数推断语言水平。已提交的评分立即保存，关闭或切换页面不会清空进度；未评分的卡不推进。可撤销最近一次且未被其他更新覆盖的评分。

卡片可暂停、继续或重置。回收站词条不出题；修改释义保留排程，需要重学时自行重置。“用这个表达练一句”是可选的模型答疑，不参与自动评分。

## 备份与迁移

词句列表底部展开“导入与导出”，通过系统文件选择器操作：

- **JSON**：完整正式词句备份，包含原句、标签、卡片和复习历史，可选择包含回收站。未完成编辑草稿不在其中。文件格式为 `parley-vocabulary`、版本 2，附带来源后端和已知模型。继续接受版本 1；旧程序无法导入版本 2。
- **导入 JSON**：先预览新增、重复和冲突，再确认。相同备份重复导入不重复创建；冲突默认保留本地，也可明确作为另一条导入。不会用备份静默覆盖个人修改。
- **CSV**：供表格阅读，每行包含语言、词句、释义、注释和一条原句，不用于完整恢复；不提供 CSV 导入。采用 UTF-8 BOM，正确处理引号与换行，并给可能被表格视为公式的字段添加单引号。

JSON 导入限制为 20 MiB、10,000 词条，并校验所有字段、来源和复习记录；超限或错误不会部分写入。导出使用同目录临时文件，成功后原子替换目标文件；取消选择不写入。

词句备份不包含账号、认证凭据、CLI 路径或完整聊天历史，但包含自己收藏的原句和注释。导入后来源作为快照保留，不自动连接另一工作区的同名聊天 ID。完整工作区（包括未完成草稿与会话）的备份方法见[本地持久化](PERSISTENCE.md)。
