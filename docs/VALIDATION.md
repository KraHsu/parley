## Codex 接入首版

- 实际运行 CLI：`codex-cli 0.154.0`，Linux x86_64；协议由该二进制生成的 TypeScript 类型核对。
- 本机既有 ChatGPT 登录经 `account/read` 读取成功；`model/list` 返回真实目录，包含 Astra 和 Luna。全新账号的浏览器 OAuth 往返未执行，避免改动当前用户登录。
- 同一 Rust 客户端真实并发运行两个独立 thread：主对话返回英文问候，辅导返回中文释义；两边均观察到增量与完成事件。测试后关闭子进程。
- 实际 Tauri/WebKit 窗口中点击连接、显示账号/模型/额度，通过主面板 Astra 与辅导面板 Luna 发送并收到真实回复，输入框保持固定；进程关闭后未残留本次 App Server。
- 自动回归覆盖：乱序 RPC 响应、双面板事件隔离、工具审批拒绝、断线解除等待、thread 创建期间取消；前端覆盖增量合并、旧连接事件丢弃、进程早退、发送失败及浏览器预览边界。
- Linux 构建与原生窗口验证不代表 Windows/macOS 已验证。断线恢复历史、长时间配额耗尽、Markdown、划词和数据库仍未实现或未验证。

操作和可选真实模型测试见 [Codex 接入说明](CODEX_INTEGRATION.md)。早期 M0 的“尚未接入”描述仅保留为历史记录。
