- Ubuntu 24.04.5 LTS x86_64 上完成 `npm run package:linux` 发行构建，生成 `Parley_0.1.0_amd64.deb`。包内包含 `parley`、`parley-cli`、三个桌面入口、安装文档与 MIT 许可证。
- 从最终 `.deb` 解包运行两项程序：CLI 帮助、原样转发 `--version`、GUI 设置与路径持久化、正常关闭和重启均通过。GUI 在独立 XDG 目录及仅 `/usr/bin:/bin` 的 PATH 下，成功读取 NVM 安装的 Codex 0.154.0 和已有本机登录，无模型调用。
- 选定 Codex 的目录仅添加到子进程 PATH，支持 npm shim 查找同目录的 Node.js；新增实际脚本执行回归测试。45 项默认测试通过（22 Rust、23 Vitest），3 项真实 Codex 测试默认跳过；格式、类型与 Clippy 检查通过。
- 桌面入口通过 `desktop-file-validate`；两个程序的 `ldd` 无缺失库；`apt-get --simulate install` 成功解析安装方案。未在当前主机执行系统级安装/卸载，也未测试干净虚拟机。
