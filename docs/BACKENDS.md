# 模型服务设置

本文适用于当前多后端开发分支，尚未随 v0.3.0 安装包发布。各服务的实际验证范围见[兼容记录](BACKEND_COMPATIBILITY.md)；有厂商预设不代表已完成真实服务验收。

主聊与语言助手可以选择不同服务，也可以为同一厂商保存多份配置。API 使用各服务商的 API 凭据与额度；Codex 使用所选本机 CLI 的官方登录；Claude Code GUI 使用 API Key。Parley 不提供共享账号或统一余额。

## 添加 API 服务

1. 打开“学习设置”，在“模型服务”中点击“添加模型服务”。
2. 选择服务商，填写配置名称、API 服务地址和自己的 API Key。密钥保存方式可选“系统凭据库”或“仅本次会话”。
3. 保存后点击“检查连接 / 读取模型”。这一步读取模型列表，不生成回答。也可以直接填写自己账号可用的模型 ID。
4. 分别选择“主聊服务”和“语言助手服务”，确认各自模型 ID，然后关闭设置开始对话。

预设包含 OpenAI、Claude、Gemini、DeepSeek、通义千问、Kimi、GLM / Z.AI 和自定义兼容服务。千问需填写所属区域的服务地址；Kimi、Z.AI 的默认地址是国际服务，其他区域需使用对应地址和凭据。服务地址填写 API 基础地址，不追加单次请求的 `responses`、`messages` 或 `chat/completions` 路径。

OpenAI、Claude 和 Gemini 使用各自协议；自定义服务需兼容 OpenAI Chat Completions。模型名称由用户选择或填写，不自动替换成其他厂商的同名模型。首版用于文本学习，不提供图片、语音或工具调用。

使用 API 的主聊和助手无需安装 Codex、Claude Code 或 Node.js。没有可用凭据时，仍可查看历史、管理词句和离线复习。

## 密钥保存与更换

“仅本次会话”在关闭 Parley 后失效。重启后服务显示“待配置”，历史、模型选择和草稿仍保留；在“编辑 / 更换密钥”中重新填写即可。“系统凭据库”依赖桌面系统提供的凭据服务；保存失败会显示错误，可改用仅本次会话，不会把密钥退回到普通配置文件。

API Key 不写入学习数据库或词句备份。删除密钥不删除本地会话和词句。当前开发版每次重新提交密钥都会建立新的凭据绑定，包括重新输入同一密钥；此后请新建对话，旧记录仍可离线查看。需要关闭后继续同一 API 会话时，使用系统凭据库保存原绑定。模型没有提供余额时，界面不推算剩余额度；回复下方只展示服务实际报告的用量。

## 使用本机 Codex

在 Codex 连接区填写自己的可执行文件绝对路径，点击连接。已有本机登录可直接复用；Parley 不安装或升级 CLI。设置可添加多份 Codex 配置，分别连接、读取模型及断开。

不同配置管理各自进程和工作目录；如果使用相同的本机登录目录，仍共享同一官方账号，不会自动隔离账号或复制认证文件。详情见 [Codex 接入说明](CODEX_INTEGRATION.md)。

## Claude Code 与终端伴随

“Claude Code（API Key）”是 GUI 后端：填写用户自己的 CLI 路径和 API Key。它使用受限制的文本学习会话，续聊只恢复该本地会话对应的成功上下文，不接管其他终端会话。

原生终端是另一入口。`parley-cli --backend claude-code --claude /path/to/claude` 直接运行用户的 Claude Code，保留其原生登录与交互。旁边的语法窗口可以选择独立 API 服务，也可以使用已配置的其他 GUI 后端。Codex 终端仍使用 `parley-cli --codex /path/to/codex`。参数、同步范围及限制见[终端伴随说明](TERMINAL_COMPANION.md)。

## 会话、停止与学习记录

更换服务会新建本地会话，旧记录保留。编辑已有配置后，旧会话继续标记原版本；选择“使用新配置开始对话”后再发送。修改模型、语言或辅导模式也会在发送前建立对应的新会话，避免把旧上下文交给不匹配的配置。

已有文字历史时，切换服务可选择“空白新会话”或“带入可见历史”，也可以取消。只更换模型或重新配置密钥时，可点击对应面板的“带入历史并使用当前模型”。新会话保留未发送草稿；带入的文字可在消息区展开查看，点击发送问题后才交给所选服务。快照包含用户与助手的可见文字及中断/失败标记，不带入远端线程、认证或协议内部内容，不同步旧会话后续的改动。上限为 200 条、24 KiB；超过时会提示选择空白会话，不自动截断或调用模型总结。

每个面板的停止按钮只停止该面板的当前请求；已收到的正文保留，另一面板继续运行。关闭窗口先保存草稿和词句，再回收 Parley 管理的请求及连接。连接失败或重启不会自动重发旧输入。

API 回复与 Codex 回复都支持选词、解释、翻译和收藏。词句保留原句、来源后端和已知模型；点击“查看原消息”可以回到仍存在的本地消息。JSON v2 备份保留这些来源信息，并继续支持导入 v1。词句备份不包含完整聊天、API Key 或未保存的编辑草稿，完整工作区备份见[持久化说明](PERSISTENCE.md)。
