# Parley 视频分镜与口播稿

用途：可交给录屏、配音和剪辑直接使用的首稿。当前不新增真实模型 API 请求；所有预置内容在画面标注“界面演示 · 示例数据”，简介说明并非实时模型调用。

整体风格：像向朋友展示一个自己做的实用工具。开头先给场景，口播以动作和感受为主，技术栈只在开发者片里点到。中文自然语速，英文短语放慢；表中时间为剪辑目标，正式录音后按实际读速留白。

核心信息：聊到一个表达，理解它，带着原句收藏，之后继续复习。

主画面使用 Web；最后以短镜头交代桌面终端入口。后者如果缺少合适素材，可只显示一句文字提示，不伪造跨端同步。

### 连续口播稿

用 AI 练英语，聊着聊着遇到一个表达：大概懂，却不知道自己该怎么用。

我做了一个开源工具，叫 Parley。左边继续聊天，右边专门解决这些卡住的地方。

比如聊做饭，遇到这句 getting the hang of。选中它，就能请旁边的助手解释词义和语法。

解释会带上你选中的内容。理解以后，还可以问一句：换成我的意思，该怎么说？

任务可以切换成“怎么说”或“翻译”。主聊和答疑分开，原来的聊天记录还在。

想留下这个表达，就连同原句一起收藏，再写下自己的释义和注释。

之后打开复习，先回忆，再看答案。让今天遇到的表达，成为下一次练习的材料。

Web 版使用自己的 API；桌面版还可以在原生 Codex 或 Claude Code 旁边配一个语言助手。

Parley 已经开源。链接放在简介里，试着留下你今天想学的一个表达。

### 剪辑说明

- 90 秒是目标时长；英文和操作停顿需要空间。如果初读超时，先删“换成我的意思”那句或将终端介绍缩成画面字幕，不加速到听不清。
- 主片不要展示数据库、依赖安装、API 厂商列表或系统错误；这些留给教程。
- 收藏是明确的用户动作，不能剪成模型解释后自动写入词句本。
- 复习段注明“之后 / 复习时”，不要伪装成时间已经过去或用户已经记住。
- 结尾只要求一个动作：打开体验入口。源码链接保留，不连续要求点赞、收藏、关注和 Star。

### 竖屏剪辑说明

### 连续口播稿

如果你已经在用 Codex，又想顺便练语言，可以在终端旁边放一个语言助手。

这是 Parley 的终端伴随模式。运行 parley-cli，继续用你自己的原生终端。

登录、快捷键和历史仍由原来的 CLI 管理。已保存的回复可以同步到旁边，方便阅读和提问。

在这里选中不懂的词句，就能请助手解释、翻译，或者连同原句收藏。

原生终端和语言助手是分开配置的；助手使用你为它选择的模型服务。

也提供 Claude Code 的终端入口。Parley 已开源，源码和使用说明放在简介里。

### 终端片字幕补充

在相关画面附近显示“同步以 CLI 已保存的消息为准”；有多个会话候选时应展示选择动作。不要写成每个 token 都实时同步。Claude Code 原生终端与 Claude Code GUI 后端是不同入口，后者需要独立 API Key，不能借这支片子暗示整个 GUI 使用订阅额度。

## 录音与交付

先用手机或麦克风试读一遍，实测时长，再锁定分镜节奏。品牌名和英文例句前后留短停顿，避免将中文术语连成一串。

每支视频交付：无字幕母版、带字幕版、SRT、封面、标题、简介、素材来源清单。项目内只保留文字脚本与计划。封面、录屏、音频、字幕、成片和制作工具全部另行存放，不进入 Git，不放入 Web 或 GitHub Release。由维护者自行发布到 YouTube 等平台。

发布前实际核对：脚本里的每个按钮与当前版本一致；描述的是 Web 还是桌面；结尾链接能打开；示例数据标识可读；没有把尚未实现的功能剪进成片。
