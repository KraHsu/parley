# 第一轮试看记录

状态：尚无真人试看记录。此表是采集模板，不是调查结果；本地 UI 验证不能替代陌生用户反馈。

## 十分钟流程

1. 展示 README 前两屏，给参与者 15 秒自行浏览。
2. 请对方用自己的话说明：这个项目做什么、从哪里开始、是否需要自己的模型凭据。先记录原话，不提示答案。
3. 看 90 秒视频，再让对方在 Web 中手动添加一个词句和释义。没有 API 凭据也能完成这个任务，不要求参与者发送密钥或购买服务。
4. 记录卡住的步骤，询问哪句话或哪个画面最难理解。
5. 看竖屏短片，静音重看一次，检查字幕、按钮和例句是否能读清。

## 判断与行动

首轮目标：5 人中至少 4 人能说明用途与凭据要求；至少 3 人能完成一次手动或示例词句收藏。样本用于发现入口问题，不用于推断学习效果。

- 用途不清：修改首屏解释和视频前 5 秒。
- 凭据要求不清：补开始使用示例，保留 API / CLI 区别。
- 收藏失败：记录步骤并转成可复现 issue。
- 字太小或口播太快：调整对应片段，不只增加字幕。
